# نرم‌افزار کافه آرین

نسخه پایه نرم‌افزار فروش و حسابداری آفلاین مخصوص کافه آرین.

## فناوری
- C#
- WPF
- .NET 10
- SQLite با Microsoft.Data.Sqlite

## اجرای پروژه
1. Visual Studio 2022/نسخه سازگار با .NET 10 را نصب کنید.
2. پروژه `CafeArian.csproj` را باز کنید.
3. اجازه دهید NuGet package ها Restore شوند.
4. پروژه را Run کنید.

دیتابیس به‌صورت خودکار در مسیر LocalApplicationData ساخته می‌شود:
`%LOCALAPPDATA%\CafeArian\cafe-arian.db`

## نسخه فعلی
- ایجاد خودکار دیتابیس
- دسته‌بندی محصولات
- محصولات نمونه
- موجودی اولیه
- فروش سریع
- جستجوی محصول
- جستجوی بارکد
- سبد خرید
- تخفیف
- ثبت فاکتور
- ثبت پرداخت نقدی پایه
- کاهش موجودی داخل Transaction

## مرحله بعد
- پنجره پرداخت نقدی / کارتخوان / ترکیبی
- ثبت مشتری با موبایل
- چاپ فیش
- مدیریت محصولات و مواد اولیه
- خرید و ورود به انبار
- دستور تهیه و محاسبه بهای تمام‌شده
- محصولات یخچالی و چاپ لیبل
- بانک‌ها و کارتخوان‌ها
- هزینه‌ها
- سود و زیان
- گزارش‌ها و نمودارها
- پشتیبان‌گیری
- کاربران و سطح دسترسی
- لغو فاکتور با Audit Log
